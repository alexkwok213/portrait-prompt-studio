# 人像提示词检查表

本技能全程只做文字生成。三部分：Route 1（从描述起手）的文字检查、Route 2（从照片反推模板）的模板检查、以及两条路线共用的出图后目视验收。

**贯穿两条路线的第一条规矩**：图像工具永远只接收文字。照片只能被视觉工具读取以反推提示词，不作为生成输入。

## Route 1 · 句式粒度（致命项，任一不通过则修正后再生成）

| ID | 名称 | 判定 |
|----|------|------|
| F0 | 无图片输入 | 图像工具调用中不含任何参考图片参数 |
| F1 | 物理自洽 | 光源方向、器材、时段一致；夜晚/室内不配日光主光 |
| F2 | 句式粒度 | 每个核心维度是完整句子（主语+特征+状态），非逗号罗列标签 |
| F3 | 语言模式 | EN 模式全文英文无中文字符；ZH 模式全中文；中英须同一场景 |
| F4 | 维度覆盖 | 已覆盖 ≥12 项核心维度（见 `text-to-image.md` §二） |
| F5 | 眼神状态 | 含眼神状态词（直视/失神/带笑意/安静聆听），非仅"big eyes"；不必每次直视 |
| F6 | 光位四要素 | 来源 + 方向 + 硬度/扩散 + 色温 + 皮肤效果与具体阴影位置 |
| F7 | 背景排除法 | 含 `no environment / no props / no plants / no foreground elements` 类排除表述 |
| F8 | 表情一致 | 眼睑、脸颊、鼻翼、嘴唇的变化属于同一反应，写成正在发生的瞬间 |
| F9 | 姿态与支撑 | 身体有支撑；每只手接触对象明确；接触褶皱与阴影方向吻合 |
| F10 | 无违禁格式 | 无 `(x:1.2)` 权重语法、无 `masterpiece/best quality` 质量标签串、无 tag soup |
| F11 | 字数 | EN 300–1000 词；ZH 300–600 字；用户另有要求时按其要求 |
| F12 | 未自动追加质感 | 未为"高级感"平白加入胶片颗粒、金色轮廓光、强浅景深、奶油肤质 |
| F13 | 未强制理想化 | 未把人物锁死在"圆脸+大眼+白瓷皮+标准微笑"；微笑非必选项 |

风格项（S）给优化建议不阻断：情绪与光影是否一致、身份与姿态是否撕裂、设备与画质是否自洽、服装细节是否够6–8 维、眼神方向与机位是否矛盾、道具位置是否交代。

## Route 2 · 模板检查

### 生成模板时

| ID | 名称 | 判定 |
|----|------|------|
| T1 | 真的看了图 | 用视觉工具打开过原图，不是读文件名/图注/记忆 |
| T2 | 三桶分明 | A 摄影关系 / B 新身份 / C 新场景设计，在模板中可区分 |
| T3 | 不冒充事实 | 相机参数、灯光器材、修图流程、隐藏支撑标为推测或设计 |
| T4 | 新身份隔离 | 原人物的可识别特征未进入模板；新身份明确写出 |
| T5 | 元素表完整 | E1–E10 全覆盖，每项有当前值与可替换范围 |
| T6 | 受保护元素 | E7 光位、E9 画幅机位、E10 成像倾向已标记为 protected |
| T7 | 中英同景 | 两版描述同一场景，无一方偷换背景 |
| T8 | 文件布局 | `templates/<slug>/` 下有 template.md；source.jpg 与 preview.png 命名正确 |
| T9 | 不得提交原图 | 模板生成与使用过程中，图像工具从未收到 source.jpg |

### 应用替换需求时

| ID | 名称 | 判定 |
|----|------|------|
| C1 | 精准定位 | 只改了用户点名的元素 |
| C2 | 其余不动 | 未点名元素保持字节一致 |
| C3 | 冲突检查 | 替换是否与 E7/E9/E10 的物理关系冲突；冲突已告知并处理或交由用户决定 |
| C4 | 中英同步 | 改了一个元素的两个语言版本 |
| C5 | 变更说明 | 产出中写明改了哪几个、保持哪几个 |

## 出图后 · 逐项目视（两条路线共用）

不自动宣布通过。文字格式或模板检查通过，都不等于图片合格。

| 项目 | 查看区域 | 通过依据 |
|---|---|---|
| 人脸 | 眼睑/虹膜、鼻唇、脸颊 | 新人物有区分特征；没有反复复用已被否定的脸 |
| 表情 | 眼睛、脸颊、嘴角、牙齿 | 各部位属于同一反应；无固定白牙条和僵硬嘴角 |
| 肤质 | 额头、鼻翼、脸颊、下巴 | 局部色差与反光符合受光；未为去 AI 感乱加瑕疵 |
| 光线 | 人脸、发缘、衣袖、家具 | 能由已指定光源、遮挡与反射解释，不像单独补亮的脸 |
| 姿态 | 肩膀、肘、手、坐垫 | 身体有支撑，手接触正确，布料与坐垫受压方向吻合 |
| 机位 | 头、肩、家具可见平面 | 透视与可见上表面符合指定高度，不用关键词当证据 |
| 景深 | 人脸、扶手、背景家具 | 清晰度沿距离变化；人物与背景无抠图/涂抹分界 |
| 整体 | 人物与场景 | 白平衡、噪点、锐化与曝光相容；模板的摄影职责得到体现 |

皮肤光滑、眼睛大、俯视、逆光和虚化均不能单独证明 AI 生成。评价这些特征的组合及其与场景的关系，不夸大成"相机不可能拍到"。

## 未达标时

标记具体部位和现象，选择最相关的一处约束修改（脸 → 光 → 姿态 → 景深，按需选一）。保存上一版，不把重复加"真实自然"称作改进。若仍有模板脸，明确报告，并说明文字路线的局限——需要完全不同的脸时，改用另一个模板或换描述，不是改成图生图。
